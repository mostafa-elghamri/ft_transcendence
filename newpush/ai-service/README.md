# AI Service

هذه خدمة Node.js مبنية بـ Express.js. مسؤوليتها الرد على أسئلة المستخدم حول مصاريفه وديونه ومجموعاته باستخدام تقنية RAG ونموذج لغوي.

قاعدة البيانات المستخدمة هي MongoDB، والاتصال بها يتم عبر مكتبة Mongoose.

## التشغيل

انسخ ملف .env.example إلى ملف باسم .env.
ضع فيه قيمة GROQ_API_KEY الحقيقية.
ضع فيه قيمة JWT_SECRET وتأكد أنها نفس القيمة المستخدمة في خدمة تسجيل الدخول الرئيسية للمشروع.
ضع فيه قيمة MONGODB_URI الحقيقية لقاعدة بيانات المشروع.

بعد ذلك نفذ الأمر التالي لتثبيت الحزم:

npm install

ثم شغل الخادم بالأمر التالي:

npm start

إذا لم تُضبط قيمة MONGODB_URI، أو تعذر الاتصال بها خلال أربع ثوانٍ، تعمل الخدمة تلقائياً ببيانات تجريبية بدلاً من التوقف.

## المجموعات المستخدمة في MongoDB

المجموعات المُعرَّفة في الملف src/models.js هي أربع مجموعات باسم users وباسم groups وباسم expenses وباسم debts.

مجموعة users تحتوي على الاسم والبريد الإلكتروني وكلمة المرور المشفرة ورابط الصورة الرمزية.

مجموعة groups تحتوي على اسم المجموعة والعملة وقائمة معرفات الأعضاء.

مجموعة expenses تحتوي على معرف المجموعة والوصف والمبلغ والعملة ومعرف من دفع وقائمة معرفات من شارك في التقسيم.

مجموعة debts تحتوي على معرف المجموعة ومعرف المدين ومعرف الدائن والمبلغ والعملة وحالة التسوية.

## نقاط النهاية

توجد نقطة نهاية باسم /api/chat تستقبل طلب POST يحتوي على حقل باسم question، وترجع إجابة كاملة مع مصادرها.

توجد نقطة نهاية باسم /api/chat/stream تستقبل نفس الطلب لكنها ترجع الإجابة تدريجياً عبر تقنية Server-Sent Events.

توجد نقطة نهاية باسم /api/sentiment تستقبل حقل باسم text وترجع تصنيف مشاعر هذا النص.

توجد نقطة نهاية باسم /health لا تحتاج توكن، وتستخدم لمعرفة حالة الخدمة.

جميع نقاط /api تحتاج ترويسة باسم Authorization تحتوي على كلمة Bearer متبوعة بتوكن JWT صالح.

## الاختبار الأمني

يوجد ملف اختبار في المسار tests/security.test.js يتأكد أن كل مستخدم لا يرى إلا بياناته الخاصة فقط.

لتشغيله يجب أولاً تشغيل الخادم بدون قيمة في MONGODB_URI، حتى تُستخدم البيانات التجريبية المنفصلة لكل مستخدم.

بعد ذلك نفذ الأمر التالي في نافذة طرفية أخرى:

npm run test:security

## ملاحظة مهمة لفريق الباك اند

الملف src/models.js يحتوي على تعريف المجموعات بأسماء افتراضية.

إذا كان فريق الباك اند قد اختار أسماء حقول مختلفة، أو قرر تضمين المصاريف داخل مستند المجموعة بدل فصلها، يجب تعديل هذا الملف والملف src/dataSource.js معاً ليطابقا التصميم الحقيقي المتفق عليه قبل الدمج النهائي.

يجب أيضاً التأكد أن جميع الخدمات في المشروع تتصل بنفس قاعدة بيانات MongoDB وبنفس أسماء المجموعات بالضبط.
